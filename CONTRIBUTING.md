# Contributing to TerriFront

Thanks for helping improve TerriFront. Contributions may include code, artwork, map data, documentation, bug reports, and gameplay ideas.

## Before submitting

- Make sure your contribution is your original work, or that you have permission to submit it.
- Do not submit WarFront code, artwork, map data, or other third-party material unless its license allows it.
- Keep changes focused and explain the purpose of the contribution.
- Run `npm run build` before opening a pull request when your changes affect the project.

Submitting a pull request, patch, issue attachment, or other contribution constitutes acceptance of these terms. If you do not agree, do not submit the contribution.

## Pull requests

Please include a short description of what changed and how it was tested. Maintainers may ask for revisions before accepting a contribution.
